# 低功耗 Wi-Fi 宠物饮水机固件

基于赛元 SC92L7533、涂鸦 Wi-Fi MCU SDK 和 SC89601 充电芯片的宠物饮水机项目。

本仓库以 **2026-09-30 所提供源码、2026-10-03 整理快照**为基线。**2026-10-09** 按用户粘贴文本核对并同步 `User/SC_it.c`、`User/main.c`、`HAL/hal_power.c`，保留其他源码和原始归档。目前适合版本管理、代码阅读和后续补齐；**不是已经完成编译验证的完整 Keil 工程**。

## 主要功能

- 感应出水与外部供电下持续出水，电池模式下自动降级。
- 本地按键及 App 开关、模式、加热、UVC、静音设置。
- 电池电量、温度、水位、TDS 水质采集与状态上报。
- 清洗与滤芯剩余天数计算、报警标志及 EEPROM 保存。
- 本地重新配网、远程重置通知、配网期间保持模组唤醒。
- Wi-Fi 休眠/唤醒握手、待发送需求、发送失败后的保留与重试。
- MCU STOP 进入、BTM 时间推进、睡眠巡检和唤醒恢复代码。
- SC89601 充电与 OTG 管理、状态快照、错误检测和看门狗维护。

以上表示源码中存在相关实现，不等同于全部通过本轮上板验收。部分涂鸦 DP 和扩展服务仍是 SDK 占位接口。

## 当前配置

| 配置 | 当前值 | 含义 |
| --- | --- | --- |
| `APP_MCU_STOP_ENABLE` | `0` | 主动进入 MCU STOP 关闭 |
| `DEBUG_IGNORE_WATER_EMPTY`（main 和 ADC） | `1` | 缺水调试旁路开启 |
| `APP_CHARGE_DEBUG` | `1` | 充电芯片调试输出开启 |
| `DEBUG_PUMP_ALWAYS_ON` | `0` | 水泵强制常转关闭 |
| `main()` 中的 `HAL_LPD_Init()` | 已注释 | 启动时不显式调用低压检测初始化；其余入口是否配置 LPD 仍需完整初始化源码确认 |

上述调试宏沿用原配置。2026-10-09 同步保留用户提供的 `HAL_LPD_Init()` 注释状态；`SC_it.c` 与 `hal_power.c` 的有效代码和基线一致。更多状态说明见 [CURRENT_STATUS.md](docs/CURRENT_STATUS.md)。

## 编译环境与补齐

源码使用 Keil C51 扩展（`bit`、`code`、`interrupt`）及赛元寄存器/驱动，不能直接按普通桌面 C 程序编译。

目前未提供原始 `.uvproj/.uvprojx`、完整赛元驱动、部分业务/HAL 头文件和 `tuya_type.h`。请先按缺失清单补齐，再将各目录加入原 Keil 工程及 Include Paths；原有 `HeadFiles` 路径也需保持可解析。现有相对引用 `..\Drivers\SCDriver_list.h` 要对应完整赛元驱动树。

本次完成文件来源核对与打包完整性验证，未执行 Keil 编译或上板测试。
