# 当前源码状态

本文件依据 2026-09-30 提交的代码记录；不是新一轮硬件验收报告。

## 已有实现

- Timer0 1ms 中断驱动蜂鸣器及每 10ms 触摸扫描；主循环消费 10/100/500ms 标志。
- 主循环处理串口；100ms 调度充电服务、FSM、UI 和水泵输出；500ms 进行完整 ADC 采样。
- BTM 每 125ms 记录一次 Tick，主循环每 8 个 Tick 推进秒任务；睡眠期间也推进已校准的时间。
- 业务状态包含关机、待机、感应、持续、缺水错误；供电环境参与负载和模式限制。
- 开关、模式、加热、UVC、静音及状态 DP；清洗/滤芯数据、时间同步、重置通知。
- Wi-Fi BOOT / WAIT_SLEEP / SLEEP / WAIT_WAKE / ACTIVE / ERROR 状态及配网保持。
- MCU STOP 的入睡复查、引脚快照、ADC/显示处理、周期巡检及恢复。
- SC89601 软件 I²C、配置确认、输入/OTG 状态检测和芯片看门狗维护。

## 当前调试配置

`User/main.c` 与 `HAL/hal_adc.c` 中 `DEBUG_IGNORE_WATER_EMPTY=1`。ADC 的水位 Getter 在此配置下固定返回有水。缺水保护代码存在，但当前调试配置不等同于正常缺水检测已启用。

`APP_CHARGE_DEBUG=1`，保留 OTG/充电调试输出。OTG 的状态确认和异常重试已经写入代码，成功与否需以测量和最新日志为准。

## 阅读时需要区分

- `wifi_uart_last_frame_tx_ok()` 只表示本地发送结果，不代表模组或云端确认。
- `WIFI_LP_SLEEP_PENDING` 是已允许/获准休眠的协议状态，不能单靠它证明已达到目标电流。
- 配网 UI 倒计时与 Wi-Fi 配网保持计时独立；取消本地提示不等于立即终止模组配网。
- `uvc_armed` 是启用设置，`timer_uvc_s` 决定实际运行时长。
- `current_unix_time` 在该实现中是相对 2000 年的秒数，不是 Unix 1970 年纪元时间。
- `HAL_Buzzer_Beep_3s()` 当前实际注入 800ms 发声时间。
- SDK 列出的 DP 与扩展功能不代表全部已实现：例如 WATER_NUM 下发处理仅返回 SUCCESS，MCU 升级函数仍有待实现内容。
- 原源码包含历史注释与现实现不完全一致的情况。本次保留原文，判断行为以执行代码和调用周期为准。
