## 源码同步

- 同步 Keil 工程、主循环、低功耗、Wi-Fi 与涂鸦 SDK 文件，以及触摸、蜂鸣器、UART、ADC 的补充文本。内容相同的文件沿用归档字节。GBK 与 UTF-8 按归档中各文件的编码保存。
- `g_uvc_exti_flag` 在 `User/SC_it.c` 中定义为 `volatile uint8_t`。触摸驱动同时含有带和不带 `volatile` 的声明，合并时保留与定义一致的声明。
- `HAL_Power_GetInputDebug()` 的定义来自用户的低功耗文本。工程从 `PWR` 编译实现，而主循环的头文件路径优先命中 `Hardware`，两个同名头文件都声明了该接口。
- 在归档的 `app_wifi.h` 中声明 `App_Wifi_GetBatDpValue()`。在归档的业务状态机中补入用户此前给出的 `App_FSM_BatteryProtectActive()` 查询及声明，供电量 DP 区分泵锁定和保护关机。其余未提供的文件沿用 2026-10-24 归档。

## 当前调试与功能配置

| 项目 | 本基线的代码行为 |
| --- | --- |
| MCU STOP | `APP_MCU_STOP_ENABLE=1` |
| Wi-Fi 自动唤醒测试 | `WIFI_TEST_AUTO_WAKE=0`，沿用归档头文件 |
| UART0 调试 | `APP_DEBUG_UART_ENABLE=1`，P1.3 用作调试 TX，暂停物理 UV 输出；应用侧开启电源日志 |
| 缺水与温度 | 主循环和 ADC 均关闭缺水旁路，实测温度使用 NTC 转换值，25℃为缓存初值 |
| UVC 长按 | P1.1 持续按下约 5 秒提交重启请求。主循环通过 `HAL_Buzzer_BeepMs(3000U)` 提示，静音时跳过发声，然后拉低 CEN 并执行 MCU 软件复位 |
| Wi-Fi 恢复 | CEN 位于 P5.1。日志 `[W13]` 的 `p=7` 为释放 CEN 后等待握手；等待 30 秒超时则进入 `p=8` 并拉低 CEN，240 秒后重试 |
| `[WH]` 日志 | 当前 `system.c` 的预处理结果裁掉 `[WH]`，其头文件链没有定义 `APP_LOG_POWER_ON` |
